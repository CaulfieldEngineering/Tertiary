# Web demo MIDI (original, written 2026-10-27)

Each piece is one loop, 4/4. The Duet project "Tertiary Web Demo" holds each piece three times in a row;
render all three and keep the middle pass (see web_tracks.py).

## Warm Pad: 60 bpm, 8 bars a pass, starts at bar 1 in Duet (passes at bars 1, 9, 17)
- `Warm Pad - WARM PAD.mid`: a warm analog pad (Analog Dreams). 182 notes a pass.

## Electric Piano: 84 bpm, 12 bars a pass, starts at bar 27 in Duet (passes at bars 27, 39, 51)
